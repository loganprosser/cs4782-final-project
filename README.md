# Bayes by Backprop Reimplementation

CS 4782 final project repository for reproducing and extending Bayes by Backprop from *Weight Uncertainty in Neural Networks*.

This repository has been reorganized for GitHub submission around the required course layout:

```text
.
├── README.md
├── LICENSE
├── .gitignore
├── code/
├── data/
├── results/
├── poster/
└── report/
```

## Repository Contents

- `code/`: source code, experiments, evaluation scripts, tests, and Kalman/trust extensions.
- `data/`: dataset notes plus local dataset downloads. Raw MNIST/Fashion-MNIST downloads are ignored by git.
- `results/`: preserved figures, tables, summaries, logs, and archived experiment outputs.
- `poster/`: final poster PDF candidate, currently `poster/kalman_down_the_noise.pdf`.
- `report/`: final report PDF candidate, supporting notes, and reference paper PDF.

## Quick Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r code/requirements.txt
```

## Core Runs

The main training scripts now live under `code/experiments/`:

```bash
python code/experiments/train_mnist.py --model bayesian --epochs 10 --mc-samples 10
python code/experiments/train_mnist.py --model bayesian --bayesian-dropout 0.1 --epochs 10 --mc-samples 10
python code/experiments/train_regression.py --model bayesian --epochs 2000 --mc-samples 100
```

By default, new core outputs go under `results/bayes_by_backprop/`.

## Notes

The code was moved from `bayes-by-backprop-reimplementation/`, which was the most complete implementation directory. Large local datasets, virtual environments, generated bytecode, and checkpoint files are excluded from git.
