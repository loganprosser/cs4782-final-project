# Results

Preserved outputs are organized by source and purpose:

- `bayes_by_backprop/`: core implementation outputs, summaries, benchmark outputs, uncertainty-shift outputs, and old checkpoints.
- `reproduction/`: reproduction CSVs, figures, logs, and checkpoints from the final four-model comparison layer.
- `figures_final/`: final poster/report-ready SVG figures from the core project.
- `figures_final_with_external_kalman/`: final figures with the external Kalman comparison included.
- `classe_plots/`: copied remote/Classe plots and summaries.
- `kalman_trust_fashion_noise10/`: Fashion-MNIST noisy-label Kalman trust summaries, curves, plots, and diagnostics.
- `archived_kalmanalgo_runs/`: archived standalone Kalman optimizer run outputs.
- `archived_sample_trust_runs/`: archived sample-trust run outputs.

Checkpoint files are kept locally when present but ignored for GitHub.
